Admin Portofolio

Masuk dengan akun GitHub untuk mengedit konten website. Perubahan disimpan langsung ke repo dan otomatis tayang setelah Vercel selesai deploy.

Token hanya disimpan di browser ini, tidak dikirim ke mana pun selain GitHub.

Cara membuat token GitHub
  1. Buka GitHub → Fine-grained tokens → Generate new token.
  2. Isi nama (misal admin-portofolio) dan masa berlaku.
  3. Repository access: pilih Only select repositories → repo portofolio ini saja.
  4. Permissions → Repository → Contents: pilih Read and write.
  5. Klik Generate token, salin, lalu tempel di atas.

Hanya orang yang punya token dengan akses tulis ke repo ini yang bisa mengubah konten.
